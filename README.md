# Scorched Guns para Horizon

Versao 0.1.2: Gun Bench (bancada) e as armas do tier Antique que dependem so de materiais comuns:
musket, flintlock_pistol, handcannon, blunderbuss e doublet. As armas ainda nao atiram (proxima versao).

Fixado no Horizon Nightly 2026-11-08, commit `fdc87aecdbd116bf1e08adcd062fcbaea8c2e2ca`.

## Instalacao (duas partes)
1. Codigo: suba estes arquivos para a RAIZ do repositorio e instale pelo launcher (Mods > Adicionar do GitHub).
2. Conteudo: coloque `scguns-content.hmod` na pasta `horizon-mods/` da instancia (botao da pasta ao lado de Jogar)
   e ative em Options > Mods.
